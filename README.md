# Надстройка-игра для PowerPoint

Это интерактивная 2D-игра, встроенная в слайд через официальный Office content add-in. Она использует HTML/Canvas/JavaScript, без VBA-макросов: огонёк движется по лабиринту, стены блокируют его, выход переводит на следующий слайд.

## Состав
- `manifest.xml` — описание надстройки для PowerPoint.
- `web/content.html` — экран игры с фоном игрового слайда и управлением.
- `web/assets/` — иконки.
- `set-host.ps1` — меняет адрес-заглушку в manifest на домен хостинга.

## Чтобы встроить игру в презентацию
1. Разместите всё содержимое папки `web` на HTTPS-сайте. Адрес должен открывать `content.html` и файлы из `assets`.
2. Запустите `set-host.ps1` с доменом сайта, чтобы заполнить URL в `manifest.xml`.
3. Зарегистрируйте надстройку в PowerPoint. В PowerPoint в браузере можно загрузить manifest через **Надстройки → Загрузить мою надстройку**. В настольном PowerPoint этот способ может быть недоступен: установка часто требует каталога надстроек организации или разрешения администратора.
4. Вставьте надстройку на игровой слайд и растяните её на весь слайд, затем сохраните презентацию.

## На компьютере показа
Откройте сохранённую презентацию в PowerPoint с поддержкой надстроек и доступом к HTTPS-сайту с игрой. Надстройки могут быть запрещены политикой организации. Это не VBA-макрос, но PowerPoint всё равно должен разрешить загрузку надстройки.

## Управление
Клавиши стрелок или WASD; также можно нажимать экранные стрелки. При достижении золотой искры надстройка переключает презентацию на следующий слайд.

## Что ещё нужно
Этот проект подготовлен, но не развёрнут на сайте и не вставлен в `.pptx`. Для полного результата нужен доступный HTTPS-хостинг и способ разрешить/добавить надстройку в PowerPoint. Content add-ins загружают веб-страницу по адресу из manifest и встраиваются в документ; сам `.pptx` не хранит исполняемую веб-страницу внутри себя.
