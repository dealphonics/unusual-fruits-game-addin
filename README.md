# Игра «Лабиринт халы» для PowerPoint

Игра опубликована отдельно от презентации. В ней нужно провести огонёк через лабиринт к выходу; после победы PowerPoint переключается на следующий слайд.

- Играть в браузере: https://dealphonics.github.io/unusual-fruits-game-addin/
- Страница игры для PowerPoint: https://dealphonics.github.io/unusual-fruits-game-addin/content.html
- Репозиторий с файлами: https://github.com/dealphonics/unusual-fruits-game-addin

## Подключение в PowerPoint

В архиве `fruit-game-powerpoint-addin.zip` лежит манифест надстройки `manifest.xml`. В PowerPoint откройте **Вставка → Надстройки** и выберите загрузку надстройки из файла, если этот пункт доступен. Укажите `manifest.xml`, затем вставьте «Лабиринт халы» на игровой слайд и растяните его на весь слайд.

Некоторые версии PowerPoint или настройки организации скрывают загрузку надстроек из файла. Тогда подключить её может администратор Microsoft 365. Игра размещена на HTTPS, работает без VBA, но для показа нужен интернет и PowerPoint, разрешающий надстройки.

Публикация размещает игру и манифест. Саму надстройку ещё нужно добавить в PowerPoint и сохранить презентацию.
